# Mail Attachment Extractor – Streamlit

Applicazione Streamlit per elaborare archivi di posta elettronica.

## Funzioni

- Upload `.mbox`, `.eml`, `.msg` e `.zip`
- Estrazione automatica degli allegati
- Lettura ricorsiva delle email presenti negli ZIP
- Sintesi locale del testo delle email
- Tabella cronologica con data/ora, mittente, oggetto, sintesi e allegati
- Ricerca e filtro delle email
- Download del report CSV ed Excel
- Download di tutti gli allegati in un unico archivio ZIP

## Streamlit Community Cloud

Main file path:

`mail_attachment_extractor/app.py`
